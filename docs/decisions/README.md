# Decisions

One file per decision that would be expensive to reverse, or that somebody will
otherwise ask about again in three months.

Each records what was decided, what else was considered, and why. If you are
about to change one of these, read it first — the reason may still hold, or it
may have been overtaken, and either way you will know which.
